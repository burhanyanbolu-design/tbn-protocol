  • "Verification Data" means the trust-state information returned by TBN endpoints.

2. Grant of Access

  • Hardin Enterprises Ltd grants the Partner a non-exclusive, revocable, non-transferable licence to access the TBN API for the stated integration purpose.

  • This licence does not grant ownership of, or rights to, the TBN Protocol, its source code, or its data.

3. API Key Security

  • The Partner must keep their API key confidential and secure.
  • The Partner must not share, publish, or embed the API key in client-side code.
  • The Partner must notify Hardin immediately if a key is compromised.

4. Permitted Use

  • The Partner may use Verification Data as contextual evidence within their own system.
  • The Partner may cache Verification Data for up to 60 seconds.
  • The Partner may display TBN certification status to their end users with proper attribution.

5. Prohibited Use

  • The Partner must not resell, sublicence, or redistribute API access to third parties.

  • The Partner must not claim TBN endorsement or partnership without written consent.
  • The Partner must not use the API for any unlawful purpose.

6. Attribution

7. Data & Privacy

  • Hardin logs API calls (timestamp, key hash, endpoint, agent_id queried) for security and billing purposes.
