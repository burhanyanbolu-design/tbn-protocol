What is Proof of Processing?

TBN receipts certify that a specific AI observation occurred under governance. They prove:

  • WHAT was processed (video hash, source URL, file size)
  • WHEN it was processed (ISO timestamp)
  • HOW it was processed (model, mode, parameters)
  • WHAT was observed (claims with individual confidence scores)
  • WHO governed it (TBN Protocol, agent ID, decision hash)

⚠️ Receipts are Proof of Processing, not Proof of Truth. AI confidence scores indicate probabilistic accuracy.

Core Endpoints

1. Process a Video

POST /api/video-agent/process

Submit a video for analysis. Returns structured intelligence + verifiable receipt.

Parameters (multipart form):

  • video — file upload (MP4/MOV/WebM, max 200MB)
  • url — OR a video URL (YouTube, Vimeo, any link)
  • mode — observe | learn | analyse | monitor | extract

2. Verify a Receipt

GET /api/verify/receipt/{receipt_id}

Publicly verify any TBN receipt. No API key required. Returns integrity status + full receipt data.

Third parties use this to confirm a receipt is authentic and untampered.

3. Ask the Agent

POST /api/video-agent/ask

Query the agent's knowledge. It synthesises answers from all videos it has observed.

Body:

{"question": "Who is [person]? What does [company] do?"}

4. Knowledge Memory

GET /api/video-agent/memory

Stats: total videos watched, entities known, facts stored, breakdown by type.

5. List Entities

GET /api/video-agent/entities?type=company

All known entities. Filter by: person, company, brand, organisation, podcast, university, location, product.

6. List All Receipts

GET /api/verify/receipts

Summary of all issued receipts. Audit trail for compliance.

Integration Example

Python — Process a video and verify the receipt:

import requests

# 1. Submit a video for governed analysis
resp = requests.post("https://tbn.hardinai.co.uk/api/video-agent/process",
    data={"url": "https://youtube.com/watch?v=...", "mode": "observe"})
result = resp.json()
receipt_id = result["receipt"]["receipt_id"]

# 2. Verify the receipt (any third party can do this)
verify = requests.get(f"https://tbn.hardinai.co.uk/api/verify/receipt/{receipt_id}")
proof = verify.json()

assert proof["verified"] == True
assert proof["proof_type"] == "PROCESSING"
assert proof["hash_integrity"] == "VALID"
assert proof["signature_integrity"] == "VALID"

# 3. Ask the agent what it learned
answer = requests.post("https://tbn.hardinai.co.uk/api/video-agent/ask",
    json={"question": "What was discussed in the video?"})
print(answer.json()["answer"])
