┌─ WHAT YOU NEED TO DO ─────────────────────────────────────────────────────────┐
│                                                                                │
│  STEP 1: Get API Key (5 min)                                                 │
│  ┌──────────────────────────────────────────────────────────────────────────┐ │
│  │ Go to: https://tbn.hardinai.co.uk/api/access/request                    │ │
│  │ Choose: TRIAL (free) or paid plan                                       │ │
│  │ Save: Your API key (tbn_live_xxx)                                       │ │
│  └──────────────────────────────────────────────────────────────────────────┘ │
│                                                                                │
│  STEP 2: Configure Boomi (10 min)                                            │
│  ┌──────────────────────────────────────────────────────────────────────────┐ │
│  │ Add HTTP Connector:                                                      │ │
│  │   URL: https://tbn.hardinai.co.uk/api/boomi/process                     │ │
│  │   Header: Authorization: Bearer tbn_live_YOUR_KEY                       │ │
│  │   Header: Content-Type: application/json                                │ │
│  │                                                                          │ │
│  │ Send one of three request types:                                        │ │
│  │   • bot_registration (register bots)                                    │ │
│  │   • certification_check (verify certs)                                  │ │
│  │   • governance_query (query status)                                     │ │
│  └──────────────────────────────────────────────────────────────────────────┘ │
│                                                                                │
│  STEP 3: Test (5 min)                                                        │
│  ┌──────────────────────────────────────────────────────────────────────────┐ │
│  │ Test health check:                                                       │ │
│  │   curl -X GET https://tbn.hardinai.co.uk/api/boomi/health               │ │
│  │                                                                          │ │
│  │ Test bot registration:                                                  │ │
│  │   curl -X POST https://tbn.hardinai.co.uk/api/boomi/process \           │ │
│  │     -H "Authorization: Bearer tbn_live_YOUR_KEY" \                      │ │
│  │     -H "Content-Type: application/json" \                               │ │
│  │     -d '{ "process_type": "bot_registration", ... }'                    │ │
│  └──────────────────────────────────────────────────────────────────────────┘ │
│                                                                                │
│  STEP 4: Deploy (1 min)                                                      │
│  ┌──────────────────────────────────────────────────────────────────────────┐ │
│  │ Activate your Boomi process                                             │ │
│  │ Done!                                                                    │ │
│  └──────────────────────────────────────────────────────────────────────────┘ │
│                                                                                │

┌─ API ENDPOINTS ───────────────────────────────────────────────────────────────┐
│                                                                                │
│  GET /api/boomi/health                                                       │
│  ├─ No authentication required                                               │
│  ├─ Returns: { "status": "healthy", ... }                                    │
│  └─ Use: Health checks, monitoring                                           │
│                                                                                │
│  POST /api/boomi/process                                                     │
│  ├─ Authentication required (API key)                                        │
│  ├─ Body: { "process_type": "...", "data": {...}, "metadata": {...} }       │
│  ├─ Returns: { "success": true/false, "result": {...} }                      │
│  └─ Use: Register bots, check certs, query status                            │
│                                                                                │
