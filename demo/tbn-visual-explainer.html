What Does TBN Do? (One Sentence)
📹

"We record and sign what the bot did."

TBN is an independent witness. We don't build the bot. We don't run the bot. We don't stop the bot. We record every decision it makes and sign it with cryptographic proof that anyone can verify.

The Governance Stack — Who Does What
L3
👨‍⚖️ Regulator / Auditor
Checks the proof. "Show me the evidence."
L2
🔐 TBN Protocol
Records & proves. Independent cryptographic witness.
L1
🛡️ Guardrail (Beyond Guard / ActTrident / Shango)
Decides if action is allowed. Blocks if not.
L0
🤖 The Bot
Does the action. Makes decisions autonomously.

Key: Guardrails = bouncer (blocks). TBN = body-cam (records). Regulator = judge (reviews footage).
